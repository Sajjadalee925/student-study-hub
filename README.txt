# Student Study Hub

A responsive, beginner-friendly static study website.

## Files
- index.html — website pages and content
- style.css — design and mobile layout
- script.js — local "Add Material" demo

## Important
The Add Material form uses browser localStorage, so added items are visible only in that browser/device. For a real public library, upload your PDFs to a suitable storage/hosting service and add their public links to the HTML.

Only publish books/PDFs that you own or have permission to distribute.

## Free publishing
You can publish this folder with a static hosting service such as GitHub Pages, Cloudflare Pages, or another service that supports static HTML.
